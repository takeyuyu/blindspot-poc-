# 「外し方には方向がある」― 人と機械の見逃しPoC

外観検査で、表面のキズを人が目視で探す。AIにも探させる。どちらも間違える。
でも――間違える「方向」が違う。

検査の誤りには二種類ある。
- **過検出（安全側）**：良品を「不良」と弾く。もったいないが、事故にはならない。
- **見逃し（危険側）**：不良を「良品」と通す。不良が世に出る。いちばん怖い。

このPoCは、人と機械が**どちらの方向に外すか**を合成データで示します。
点数（全体精度）ではなく、外す方向の違いが主題です。

## このコードが示すこと

2000個の部品（うち約15%が本当の不良、その一部が「想定外の形」の不良）を検査する状況を合成し、
人と機械の判定をモデル化する。

- **人**：迷うと安全側に倒れる（「怪しければ弾く」）。良品をやや弾きすぎるが、
  不良はあまり通さない。疲労や個人差で見え方はばらつくが、未知の不良も違和感で拾える。
- **機械**：良品をほとんど弾かない（歩留まりは良い）。よくある不良はほぼ完璧に捕まえる。
  だが学習にない「想定外の不良」を、危険側（見逃し）に、しかも自信ありげに通す。

結果（例）：
- 良品を弾く（安全側）：人 約9% / 機械 約2% … 機械が優秀に見える
- 不良を通す（危険側）：人 約8% / 機械 約12% … 機械の方が多く通す
- とくに「想定外の不良」を通す割合：人 約7% / 機械 約60%

全体精度では機械が優秀に見えても、いちばん怖い「不良を通す」を、機械は想定外で大量にやる。
しかも、閾値を安全側に振っても救えない。機械は想定外の不良を「怪しい」とすら思っておらず、
自信を持って良品と判定するため、厳しくしても引っかからないからだ。
人の「なんか変だ、止めておこう」は、機械に最も欠けている――だから両者は補い合える、という考察に繋がります。

## 前提と位置づけ

- **実データは一切使用していません。** すべて合成データによる、振る舞いのモデル化です。
- 具体的な数値は検出モデルの仮定に依存します。傾向（外す方向の違い）の例示が目的です。
- 外観検査は一例で、人とAIで失敗の質・方向が異なるあらゆる場面に通じる話として扱っています。
- 原理確認の第一歩であり、実機での性能を示すものではありません。

## 実行方法

```
pip install numpy matplotlib
python blindspot_poc.py
```

出力（同じフォルダ）：
- `blindspot.png`
  - 左：どちらの方向に外すか（安全側＝良品を弾く／危険側＝不良を通す）
  - 右：いちばん怖い「不良を通す」を、よくある不良 vs 想定外の不良で分解

※ 日本語ラベルの表示には日本語フォント（Noto Sans CJK JP など）が必要です。

## ファイル構成

## 考え方の要点

```
全体精度（当てる力）だけ見ると、機械が優秀に見える。
だが「間違えるとき、どっちに外すか」が、人と機械で逆。
人＝安全側（良品を弾く）。機械＝想定外で危険側（不良を通す）。
取り返しがつかないのは、危険側の見逃し。だから人の目が要る。
```
